# RPGV v5 结构参考

1024 整图 / 1m 数据协议；使用编码器深层特征的多尺度上下文，轻量几何条件融合、自顶向下解码和轮廓修正。几何、上下文、轮廓、结构损失消融和 RGB 容量对照均保留。

入口：configs/v5/rpgv_v5.py；configs/v5/controls/。

所有版本现在默认使用 1024×1024、1m WWTP 整图与一致的精确翻转增强。512 thumbnail 是部分旧版本的全局上下文输入，不是训练图像裁剪尺度。模型结构、损失开关和权重迁移保留；阶段预算仍按各版本配置。当前使用方式以 [README](../README.md) 和实际配置为准。

详细原设计、历史实验日志与审计保存在 `experiment-logs/2026-10-07` 分支，可用 `git show experiment-logs/2026-10-07:docs/rpgv_v5_design.md` 阅读。主分支不保留历史结果报告。
